# 写真の位置情報（Exif）消しゴム（PrivacyPhoto）
写真に含まれる位置情報（GPS）やExifメタデータをブラウザ内で検出し、消去するWebツールです。

## こんなときに
- SNSやブログ、フリマアプリに写真を投稿する前に、自宅や撮影場所のGPS位置情報が入っていないか確認したいとき
- 写真に記録された撮影日時やカメラ・スマートフォンの機種情報などのメタデータをまとめて消去したいとき
- 外部の画像処理サイトへ写真をアップロードせずに、手元のブラウザだけで処理したいとき

## 主な機能
- 写真内のExifメタデータ（GPS緯度・経度・高度、撮影日時、メーカー・機種名、撮影設定、ソフトウェア、画像の向き）の自動解析とリスク表示
- 検出されたGPS座標をGoogle マップで確認できるリンク生成（クリック時のみ座標を開きます）
- Canvas再描画によるメタデータを含まない新しいJPEG画像の生成
- 処理後の画像データに対するExif再検証（メタデータが残っていないことの自動再チェック）
- 撮影時の向き（Exif Orientation）を維持した画像出力と、透過PNGの白背景合成

## 使い方

### ブラウザで使う（かんたん）
1. [PrivacyPhotoを開く](https://zero-dev.jp/privacy-photo/) をクリックします。
2. 「写真を選択する」を押して画像を選ぶか、点線の枠内に写真をドラッグ＆ドロップします。
3. 画面に「メタデータ解析結果」（GPS位置情報の有無や撮影情報）が表示されます。
4. メタデータを消す場合は、「🛡️ Exifメタデータを消去する」を押します。
5. 「✨ 処理完了・Exif再検証」の結果が表示されたら、「💾 クリーン画像を保存する」を押して保存します（`[元ファイル名]_clean.jpg` として保存されます）。

## うまくいかないとき
- ファイルが読み込めないとき: 対応形式（JPEG / PNG / WebP）か、ファイルサイズが50MB以下かを確認してください。iPhoneのHEIC形式はJPEGに変換してから読み込んでください。
- 解像度が大きすぎるエラーが出るとき: 1辺が16,384pxを超える画像や総画素数が約6,710万画素を超える画像は、ブラウザの描画上限により処理できない場合があります。画像を縮小してからお試しください。

## 動作環境
- モダンブラウザ（Google Chrome, Apple Safari, Mozilla Firefox, Microsoft Edge の最新版）
- スマートフォン・タブレット・PC対応

## 制限・注意
- 対応入力形式: JPEG / PNG / WebP（最大50MBまで）。HEIC / HEIF / GIF / TIFF / RAW形式などには対応していません。
- 出力仕様: 入力がPNGやWebPであっても、処理後の画像はすべてJPEG形式（品質92%）で出力されます。再エンコードを行うため、元の画像からファイルサイズや画質がわずかに変化します。
- 透過画像の扱い: PNGやWebPの透明な部分は、黒くつぶれるのを避けるため白背景（`#FFFFFF`）と合成されます。アニメーションPNGやアニメーションWebPは静止画になります。
- 消えるもの・消えないもの: ExifメタデータやXMP・IPTCなどの付加情報は除去されますが、写真そのものに写り込んでいる被写体（看板、建物、風景、マンホールなど）は消えません。公開前に写真の見た目もあわせてご確認ください。

## 外部通信
写真の読み込み・解析・消去処理において、外部への通信は行いません。すべての処理はお使いのブラウザ内で完結します。
※GPS位置情報が検出された際に表示される「🗺️ Google マップで位置を確認」のリンクをクリックした場合のみ、新しいタブで Google マップ（`https://www.google.com/maps`）を開きます（写真データそのものは送信されません）。

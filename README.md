# PrivacyPhoto

写真に含まれる位置情報（Exifメタデータ）をブラウザ内で検出し、消去するWebツールです。
画像処理は端末のブラウザ内で行われ、写真データが外部のサーバーに送信されることはありません。

## 使い方

1. 「写真を選択する」ボタンをクリックするか、ドロップエリアに画像をドラッグ＆ドロップします。
2. 撮影位置情報（GPS緯度・経度）、撮影日時、カメラ機種名などの検出結果が表示されます。
3. 「Exifメタデータを消去する」ボタンをクリックすると、メタデータを含まない画像が生成されます。
4. 「クリーン画像を保存する」ボタンをクリックして、処理後の画像（`[元ファイル名]_clean.jpg`）をダウンロードします。

## 対応形式と出力仕様

- 対応入力形式: JPEG / PNG / WebP
- 非対応形式: iPhone等のHEIC形式には直接対応していません。端末の設定や変換ツール等でJPEG形式にしてからご利用ください。
- 出力形式: すべてJPEG形式（画質92%）で出力されます。
- 画質と透過処理: Canvasによる再エンコードを行うため、元画像からわずかに画質が変化します。PNGなどの透明な領域は白背景に変換されます。

## 消えるもの・消えないもの

- 消えるもの: Exifメタデータ（GPS位置情報、撮影日時、カメラ・端末の機種名、撮影設定など）。
- 消えないもの: 写真そのものに写っている被写体（看板、ランドマーク、電柱、景観など）です。画像の内容から場所が特定される可能性は残るため、公開前に写真の内容もご確認ください。

## 通信について

- 写真の読み込み・解析・消去処理は、すべてブラウザ内で完結します。外部サーバーへの画像送信や計測タグ、外部フォントの読み込みは行っていません。
- 画面上の「Google マップで位置を確認」リンクをクリックした場合のみ、検出された緯度・経度がGoogle マップに送信されます（写真データは送信されません）。
